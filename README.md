# پروژه یکپارچه ELARO

این پوشه نسخه یکپارچه و مرتب‌شده دو فایل ZIP ارسالی است.

## اجرا در VS Code
1. فایل ZIP را Extract کنید.
2. پوشه `ELARO-Complete` را در VS Code با گزینه **File > Open Folder** باز کنید.
3. افزونه **Live Server** را نصب کنید.
4. روی `index.html` راست‌کلیک و **Open with Live Server** را انتخاب کنید.

## ساختار پروژه
- `index.html`: صفحه اصلی
- `pages/`: خدمات، جزئیات خدمات، پزشکان، درباره ما، تماس، رزرو و پیگیری
- `admin/index.html`: پنل مدیریت نمایشی
- `css/`: استایل اصلی و واکنش‌گرایی
- `js/`: منطق عمومی، داده‌ها، رزرو، پیگیری و پنل مدیریت
- `assets/images/`: تصویر جایگزین

## امکانات نسخه نمایشی
- صفحه اصلی و کارت خدمات و پزشکان
- جست‌وجو و فیلتر خدمات
- صفحه جزئیات هر خدمت
- رزرو مرحله‌ای خدمت، پزشک، تاریخ و ساعت
- ثبت رزرو و تولید کد پیگیری
- پیگیری و لغو نوبت
- پنل مدیریت نمایشی برای مشاهده/لغو نوبت، تغییر قیمت و فعال/غیرفعال کردن پزشک
- ذخیره اطلاعات در LocalStorage
- طراحی RTL و واکنش‌گرا

## ورود به پنل مدیریت
از مسیر `admin/index.html` وارد شوید.
رمز نمایشی: `elaro123`

## نکات مهم پیش از انتشار
- این پروژه فقط فرانت‌اند است. LocalStorage داده‌ها را فقط در همان مرورگر ذخیره می‌کند.
- رمز پنل مدیریت در کد جاوااسکریپت قرار دارد و امنیت واقعی ندارد.
- جلوگیری از رزرو هم‌زمان بین چند کاربر، احراز هویت واقعی، پیامک، پرداخت و پایگاه داده نیازمند بک‌اند است.
- اطلاعات پزشکان، قیمت‌ها، آدرس، تلفن و سایر داده‌ها نمونه هستند و باید جایگزین شوند.
- تصاویر از URLهای خارجی استفاده می‌کنند؛ برای نسخه نهایی، تصاویر دارای مجوز را دانلود و در `assets/images/` ذخیره کنید و آدرس‌های `js/storage.js` و صفحات را به مسیر محلی تغییر دهید.
- برای شروع، می‌توانید اطلاعات خدمات و پزشکان را در `js/storage.js` و رنگ‌ها را در ابتدای `css/style.css` ویرایش کنید.

## بازنشانی اطلاعات آزمایشی
در کنسول مرورگر اجرا کنید:
```js
localStorage.removeItem("elaro_demo_v1");
location.reload();
```

## به‌روزرسانی رابط کاربری و پنل مدیریت
- پنل مدیریت خدمات: افزودن خدمت، ویرایش نام، دسته‌بندی، توضیحات، قیمت، مدت و تصویر، و حذف خدمت.
- تصاویر انتخاب‌شده در پنل به‌صورت فشرده در مرورگر ذخیره می‌شوند؛ برای نگهداری دائمی و چندکاربره باید بک‌اند و فضای ذخیره‌سازی سرور اضافه شود.
- صفحه پزشکان: کارت‌های توسعه‌یافته با سابقه، حوزه فعالیت، توضیحات و اطلاعات تحصیلی نمونه. اطلاعات واقعی و مدارک را پیش از انتشار جایگزین کنید.
- صفحه اصلی: اسلایدر چهار نظر نمونه. این متن‌ها ساختگی و صرفاً برای نمایش رابط کاربری هستند؛ نظر واقعی را فقط با اجازه مراجعه‌کننده منتشر کنید.
- صفحه خدمات: گالری سه‌اسلایدی قبل/بعد. برای جایگزینی تصاویر، فایل‌های خود را در `assets/images/` با نام‌های `gallery-1-before.jpg`، `gallery-1-after.jpg`، `gallery-2-before.jpg`، `gallery-2-after.jpg`، `gallery-3-before.jpg` و `gallery-3-after.jpg` قرار دهید.
- صفحه رزرو: تقویم ماهانه با امکان جابه‌جایی ماه، نمایش روزهای غیرقابل انتخاب و ساعت‌های آزاد.
- جست‌وجو و فیلتر خدمات با ظاهر جدید و جست‌وجو در نام، توضیحات و دسته‌بندی.

**توجه:** پنل و رزرو همچنان نسخه نمایشی فرانت‌اند هستند و داده‌ها در LocalStorage همان مرورگر ذخیره می‌شوند. پیش از استفاده واقعی، امنیت، حساب‌های کاربری، همگام‌سازی رزروها و نگهداری تصاویر باید به بک‌اند منتقل شوند.
